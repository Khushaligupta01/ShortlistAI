# ShortlistAI — Exhaustive Feature Inventory

This document establishes the verified inventory of all features, frontend routes, backend endpoints, database entities, roles, expected behaviors, implementation statuses, and test coverage across the **ShortlistAI** platform.

---

## 1. System Architecture & Foundation

- **Frontend**: Next.js 15 (App Router), React 19, TypeScript, Tailwind CSS with customized Warm Neutral Design Tokens (`#FAF9F6` base, `#FFFFFF` cards, `#756653` accents, `#292722` charcoal typography).
- **Backend**: FastAPI 0.115, SQLAlchemy 2.0 (Asynchronous), Alembic migrations, Pydantic v2 validation.
- **Database**: PostgreSQL 16 (production/CI) / SQLite via `aiosqlite` (development/testing).
- **AI Integrations**: Pluggable `LLMProvider` protocol with `OpenAIProvider` (production) and deterministic `MockLLMProvider` (development/automated CI testing).
